#  API Application Project with .NET 8
API application that allows users to create, read, update, and delete products.
It incorporates modern software development practices such as Authentication and Authorization, Generic Repository pattern, 3-tier Architecture, and Data Transfer Objects (DTOs).

## Technologies and Tools
● .NET 8 ● C# ● Entity Framework Core ● SQL Server ● ASP.NET Core ● Postman ● Visual Studio 
- *Authentication and Authorization*: Secure your endpoints using JWT.
- *Generic Repository Pattern*: Abstract data access logic.
- *3-Tier Architecture*: Separation of concerns into Presentation, Business Logic, and Data Access layers.
- *DTOs (Data Transfer Objects)*: Streamline data transfer between layers.
- *Dependency Injection (DI)* For managing dependencies and achieving loose coupling.
